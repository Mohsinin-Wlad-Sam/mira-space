API console

Make a key, try a call, and watch what it costs. A key is optional: without one the API answers 300 calls in ten minutes; with one, ten times as many, counted in credits.

This copy of the site is static. It has no server process, so there is no API and no keys here. Run it with cd web && npm run dev, or see Deploy.
